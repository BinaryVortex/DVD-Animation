# DVD-Animation

A small, lightweight isometric scene animation built with HTML and CSS.

![Preview of the DVD Animation](./Screenshot%202024-08-30%20133654.png)

Live preview
- Open `index.html` in your browser (double-click the file or serve it with a local web server).
- Recommended: use the "Live Server" extension in VS Code for instant reload while editing.

What this project contains
- An isometric scene composed with HTML elements and styled entirely with CSS.
- Animated items: cloud, shuriken, coin, and totem — driven by CSS keyframes and CSS variables for easy customization.

Quick start
1. Clone the repository:

   git clone https://github.com/BinaryVortex/DVD-Animation.git

2. Open the project folder and open `index.html` in your preferred browser.

Customization
- Most visuals and animation timings are controlled through CSS variables in `style.css` (see the `:root` block).
- Try changing colors, sizes, or animation durations to create your own variations.

Notes
- This project is minimal by design and does not require a build step or external libraries — edit the files and refresh your browser to see changes.
- Although the original description mentions JavaScript, the current implementation is CSS-driven — no external JS file is required.
